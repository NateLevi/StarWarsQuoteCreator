# Star Wars Quote Creator

Create a list of your favorite star wars quotes, then have darth vader invade the site to replace yodas quotes. May the force be with you.

# Tech used

Html, CSS, Javascript, Node.js, Npm, express, ejs, mongodb

# Lessons Learned:

The main lesson learned was node. I learned how to use modules and packages, create my own api, store the data on a database (mongodb), use CRUD process or post,get,put,and delete with express and create a updating html file. 

# Installation

run node server.js

Navigate to localhost:3000
